# dataset（学習データ）

両手ピースの分類モデルを作るための録画置き場。本番の `raspi/` とは切り離してある。

## 流れ

1. Pi を置く予定の場所に設置する
2. コンソールのカメラ欄で「録画」を押す。Pi の画面にはピースカメラと同じ位置にプレビューが出るので、画角を見ながら撮る
3. 「停止」を押す（録画中のファイルは停止で書き出しが完了する）
4. 「録画を Mac に取り込む」を押す → `dataset/recordings/` に入る

録画の設定は `pi_peace.py` が認識に使う映像と同じ: 640×480 / 15fps / 左右反転、H.264 4Mbps（約 30MB/分）。
ファイルは `rec_YYYYmmdd_HHMMSS.h264`。コンテナなしの H.264 なので、fps は 15 として扱う。

```sh
ffprobe -v error -count_frames -show_entries stream=width,height,nb_read_frames dataset/recordings/rec_*.h264
```

## 撮っておきたい場面

| 種類 | 場面 |
| --- | --- |
| 両手ピース（正解） | 距離（近い・普通・遠い）、画面の位置（左・中央・右）、手のひら側と甲側、手の高さ、何人か違う人 |
| 紛らわしいもの（不正解） | 片手だけのピース、指3本・1本、親指を立てる、パー、グー、ピースしかけ・下ろしかけ |
| 関係ないもの（不正解） | 誰もいない、通り過ぎる人、座って作業している人、物の出し入れ |
| 環境の変化 | 照明のオン・オフ、窓からの光（時間帯） |

目安は合計 10〜20 分。写る人には撮る前に一声かける。

## Pi に書き込むもの・元に戻し方

Pi で書き込むのは `~/peace-dataset/` の中だけ（`recordings/`、`record.pid`、`record.log`）。Pi にスクリプトやパッケージは入れていない。

```sh
# 録画を止めてから、Pi の録画をすべて消して元に戻す（取り込み済みか確認してから）
ssh "$PI_HOST" 'rm -rf ~/peace-dataset'
```
