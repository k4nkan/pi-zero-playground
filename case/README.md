# case（3D プリント用）

7 インチ HDMI モニター用のモニタースタンド。設計は OpenSCAD（[monitor_stand.scad](monitor_stand.scad)）で、寸法はすべて先頭の変数で変えられる。

## モニタースタンド

前の足と後ろの低い三角（高さ 10mm）のあいだの溝（`slot_w` = 5.1mm）にモニターの下の縁を差し込む。横幅 30mm（`width`）。溝は `tilt`（初期値 10°）だけ後ろに傾いている。

前の足は、座ったクマのぬいぐるみが前に投げ出した足の形。一辺 30mm（`foot_size`）の角を丸めた正方形（角の丸み `foot_corner` = 9mm）の断面を前に伸ばした棒で、正面に角丸の四角い足の裏がある（縁は `fillet` で丸める）。足の裏の溝（肉球の輪郭のような線）は、細い溝が印刷で潰れやすいので今は彫っていない（`pad = true` で彫れる）。足の長さは溝から 12mm（`foot_len`）。

足と後ろ側は、溝の下の土台（厚さ `base_t` = 4mm）でつながっている。土台は足の中まで `base_overlap`（6mm）食い込ませてあり、足と面でつながるので折れにくい。後ろの土台と三角は、正面から見えないので角を丸めていない（丸めると下向きの面ができて印刷で垂れやすいため）。後ろ側は、正面から見た足の輪郭より `hide_margin`（1mm）内側に収めてあるので、正面からは足の陰に隠れてつなぎ目が見えない。

モニターの左右に1個ずつ置く。足のつま先が少し外側を向く（`toe_out` = 8°。足の中心は後ろ側の中心とそろえてある）ので、**左用と右用を1個ずつ印刷する**。大きさは1個あたり約 31 × 37 × 29mm。

## プレビュー

1. OpenSCAD を入れる（Homebrew の通常版は配布停止中なので開発版）: `brew install --cask openscad@snapshot`
2. `open case/monitor_stand.scad` で開き、`F5` でプレビュー（マウスで回せる）
3. 「Design → Automatic Reload and Preview」をオンにすると、ファイルを保存するたびに表示が更新される
4. 先頭の `part` を `"left"` / `"right"` / `"both"`（左右を並べる）に変えると表示が変わる

## STL を書き出す

左右を並べた 1 つの STL（約 71 × 37 × 29mm）に書き出す。スライサーへの読み込みが 1 回で済む。

```sh
openscad -D 'part="both"' -o case/monitor_stand_both.stl case/monitor_stand.scad
```

片方だけ刷り直すときは `part="left"` / `"right"` で書き出す。

STL は生成物なのでコミットしない（`.gitignore` 済み）。

## 印刷のメモ

- STL は土台を下にした向きで出るので、そのまま置く
- サポートは基本的に不要（45° より寝た下向きの面は、足の底の地面から 1mm ほどだけ）。台からはがれそうならブリムを付ける
- 溝がきつい・ゆるいときは `slot_w` を 0.2mm ずつ変える
- OIC なら H 棟 1 階の KOBO（3D プリンター Adventurer 5M Pro など）で印刷できる。予約は TRY FIELD の「個別相談」から「機器利用相談」
